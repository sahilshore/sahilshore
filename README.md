## What I build

I’m **Sahil Khan**, an AI/ML builder focused on turning data, models, and language interfaces into useful software. My work sits at the intersection of **Generative AI, agentic systems, applied machine learning, and MLOps**.

```text
real problem → reliable data → model / agent → evaluation → API / product → deployment
```

My strongest signal is end-to-end ownership: I like taking an idea from ingestion and retrieval through model behavior, interface design, observability, and reproducible delivery.

## Proof of engineering mindset

<img src="./id-dashboard.svg?v=2" alt="Engineering dashboard" width="100%">

- **Grounded systems:** retrieval and explicit context flow are first-class design choices.
- **Reproducible experiments:** data, pipelines, artifacts, and model versions are treated as part of the product.
- **Useful interfaces:** models become more valuable when exposed through clear APIs, chat experiences, or browser workflows.
- **Measured iteration:** inspect failure modes, improve the workflow, and keep the setup understandable.
