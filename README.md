## About

I am **Sahil Khan**, an AI/ML builder focused on turning machine-learning ideas into practical software. My work spans **generative AI, agentic workflows, retrieval-augmented generation, NLP, computer vision, and MLOps**.

I enjoy working across the complete lifecycle:

```text
Problem → Data → Model / Agent → Evaluation → API / UI → Deployment
```

## Featured work

### [YouTube Comment Insights Engine](https://github.com/sahilshore/youtube-comment-insights-engine)
End-to-end NLP and MLOps system for YouTube comment sentiment analysis, paired with a [Chrome extension](https://github.com/sahilshore/yt-chrome-plugin-frontend). Includes a Flask API, TF-IDF + LightGBM classification, DVC pipelines, MLflow tracking, Docker, and CI/CD.

### [Sahil Voice Agent](https://github.com/sahilshore/Sahil-Voice-Agent)
Voice-first conversational AI application combining Streamlit, LangChain, LangGraph, FAISS retrieval, intent routing, and speech input/output.

### [OpenAI Multimodal Agent](https://github.com/sahilshore/OpenAI-Multimodal-Agent)
Conversational agent supporting text, image understanding, and audio transcription through OpenAI APIs and Chainlit.

### [Auto-RAG PgVector Assistant](https://github.com/sahilshore/Auto-RAG-PgVector-Assistant)
Document-grounded RAG application using PDF ingestion, OpenAI embeddings, PostgreSQL + pgvector, Docker, web-search fallback, and LLM answer generation.

### [Agentic AI Chainlit Assistant](https://github.com/sahilshore/Agentic-AI-Chainlit-Assistant)
Tool-using ReAct agent with LlamaIndex, Chainlit, and Groq for interactive reasoning and extensible Python tool execution.

### [LlamaIndex Agentic RAG Assistant](https://github.com/sahilshore/LlamaIndex-Agentic-RAG-Assistant)
PDF question-answering system using Hugging Face embeddings, semantic retrieval, LlamaIndex agentic reasoning, and Groq inference.

## Engineering principles

- **Ground outputs in evidence:** use retrieval, citations, and explicit data flow where correctness matters.
- **Make experiments reproducible:** track data, parameters, artifacts, and model versions.
- **Ship the interface too:** pair models with clear APIs, usable UIs, and straightforward setup.
- **Prefer measurable progress:** evaluate the system, inspect failure modes, and iterate.
